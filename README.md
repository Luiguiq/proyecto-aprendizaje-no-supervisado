# proyecto-aprendizaje-no-supervisado
Cálculo serial y paralelo (multithreading, 1-8 hilos) de la distancia euclidiana mínima y máxima entre todos los pares de puntos de un dataset binario en disco. Java , sin librerías, sin ArrayList, procesamiento por bloques con RandomAccessFile. Proyecto de Aprendizaje No Supervisado.
